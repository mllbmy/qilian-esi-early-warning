# `reports/` — in-repo landing directory for generated Chinese reports

This directory is the **in-repo** landing point for Chinese analysis reports written by pipeline
scripts. It is deliberately *not* the manuscript, and it is *not* submission material; the
numeric sources of every figure and table remain `data/*.csv`.

| file | written by | note |
|---|---|---|
| `robustness_loo_indicators.md` | `run_robustness_loo_indicators.py` | Leave-one-target (去重叠) robustness report. Every sentence in it is generated by the script from the computed values — no hardcoded conclusions. The same run also writes `data/results_robustness_loo_indicators.csv`. |

The report itself is created at run time, so a fresh clone contains only this note until the
script is run. The script creates this directory automatically before writing
(`os.makedirs(..., exist_ok=True)`), so no manual `mkdir` is needed:

```powershell
python run_robustness_loo_indicators.py     # refuses to overwrite existing output; add --overwrite to replace
```

History: before this cleanup round the report was written to `../审稿意见/…`, i.e. a local
private directory *outside* the repository. A cold clone could not write there (and would
either fail or scatter files on the reader's disk). The landing point is now a repository-relative
path inside `reports/`.
